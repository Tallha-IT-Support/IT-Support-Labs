# Day 1 — What Is a Computer? Hardware Components

## Key Concepts

A computer takes input, processes it via CPU and memory, and produces output.
Core components: CPU (processes instructions), RAM (short-term memory, wiped on power-off),
storage (HDD/SSD, permanent), motherboard (connects everything), PSU (power supply).


## Why It Matters

Most "my PC is slow" tickets trace back to low RAM or a dying HDD, not malware,
so an L1 tech checks RAM/storage health before anything else.


## Interview Q&A

**Q: What's the difference between RAM and storage?**

RAM is short-term working memory that clears on power-off; storage holds data
permanently even without power. A PC needs both.
