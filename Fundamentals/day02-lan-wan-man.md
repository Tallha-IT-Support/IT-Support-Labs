# Day 2 — What Is a Network? LAN, WAN, MAN

## Key Concepts
A LAN covers one building/office. A WAN connects LANs across cities or countries
(the internet is the biggest WAN). A MAN covers a city, sitting in between.

## Why It Matters
If a user can print locally but has no internet, the LAN is healthy and the
problem is isolated to the WAN edge (router/ISP) — a key first triage question.

## Interview Q&A
**Q: User says "internet is down" but can still print to a network printer. What does that tell you?**
The LAN is healthy; the problem is likely the router, modem, or ISP connection, not the internal network.
