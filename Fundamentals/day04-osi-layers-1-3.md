# Day 4 — OSI Model — Layers 1-3

## Key Concepts
- Layer 1 (Physical): cables, ports, signals
- Layer 2 (Data Link): MAC addresses, switches — same-LAN communication
- Layer 3 (Network): IP addresses, routing — between different networks

## Why It Matters
Naming the correct layer in a ticket makes escalations far more credible:
unplugged cable = L1, switch port misconfig = L2, wrong gateway = L3.

## Interview Q&A
**Q: What OSI layer does a switch operate at, and why?**
Layer 2 — switches forward traffic based on MAC addresses within a local network.
