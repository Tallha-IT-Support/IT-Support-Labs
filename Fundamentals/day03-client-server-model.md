# Day 3 — Client-Server Model & How the Internet Works

## Key Concepts
A client (browser) requests data; a server provides it. Visiting a website sends
a request through your router and ISP to a web server, which sends the page back.

## Why It Matters
Helps triage "website won't load": is it the client (browser/DNS/local network)
or the server/site itself down for everyone?

## Interview Q&A
**Q: How would you troubleshoot "Google works but our company site doesn't load for anyone"?**
Since Google works, local network/internet access is fine. I'd check if the site is
down for everyone via a status checker, then check DNS resolution and server status.
